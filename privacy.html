Animation Prints — Privacy

Prototype privacy notice. This page describes the current test journey and must be replaced or expanded with a legally reviewed privacy notice before live orders.

What the prototype processes

The prototype may process an uploaded photograph, an optional room photograph, selected style/scene/product choices and information entered into the simulated checkout form.

AI image processing

Uploaded images are sent from the application server to the configured AI image-generation provider solely to create the requested artwork or room visualisation. The production configuration should use the provider's applicable business/API terms and data-processing documentation.

Test mode

In the current test journey, checkout is simulated. No payment is taken, no printing supplier receives an order and the checkout details are not intentionally stored by the prototype.

Production launch

Before launch, Animation Prints should implement a proper privacy notice, retention/deletion schedule, lawful basis, processor contracts, cookie/analytics disclosures, customer data security controls and any required UK GDPR/PECR compliance measures.

Children

Customers may upload family photographs, but the service should not be designed to collect children's personal data directly from children. Production onboarding and age/consent requirements should be legally reviewed.
