# Permanent AI style examples

This directory is reserved for the eight permanent customer-facing style-example images used by the Animation Prints style catalogue.

Required files:
- 3d-cartoon.jpg
- anime.jpg
- fairytale-animation.jpg
- comic-book.jpg
- chibi.jpg
- watercolour.jpg
- pencil-illustration.jpg
- pop-art.jpg

These are static catalogue assets. They are not generated from customer photos and should never be generated per customer.

The production UI can fall back to the illustrated placeholders until the eight approved JPGs are uploaded here.
